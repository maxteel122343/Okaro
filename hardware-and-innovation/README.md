# Hardware Prototyping, CAD & Innovation Techniques

Collection of open-source tools, curated lists, and AI skills for:

- **Hardware prototyping & open hardware design**
- **CAD / Code-CAD / parametric modeling**
- **Electronics design**
- **Creativity & innovation techniques** (SCAMPER, Design Thinking, Design Sprint, lateral thinking)

## Included Projects

| Folder | Description | Source |
|--------|-------------|--------|
| awesome-hwd-tools | Curated list of open source hardware design tools (chip/FPGA focus) | TM90/awesome-hwd-tools |
| awesome-opensource-hardware | Awesome list of open source hardware tools, generators & designs | aolofsson/awesome-opensource-hardware |
| awesome-maker | Curated list of Maker resources (CAD, electronics, 3D printing, etc.) | digitalhackerspace/awesome-maker |
| curated-code-cad | List of code-based CAD projects (OpenSCAD, CadQuery, build123d, etc.) | Irev-Dev/curated-code-cad |
| text-to-cad | AI-powered design of physical products from text | earthtojake/text-to-cad |
| tscircuit | Create real electronics with TypeScript and React (PCB, schematics) | tscircuit/tscircuit |
| partcad | Package manager for modular hardware / digital thread | partcad/partcad |
| Form | AI hardware design workspace (CAD, BOM, assembly from ideas) | caid-technologies/Form |
| lateral-thinking | Lateral thinking skills for AI agents (includes SCAMPER, Six Hats, etc.) | danium/lateral-thinking |
| design-thinking-skills | Design Thinking skill for AI (phases, SCAMPER, templates) | rastian/design-thinking-skills |
| design-sprint | Product Design Sprint / Process Playbook | messydesign/design-sprint |

## Notes

- All are shallow copies (no full git history) for lightweight reference.
- Prefer code-CAD (OpenSCAD, CadQuery/build123d) and AI tools for rapid prototyping.
- SCAMPER is available in `lateral-thinking/skills/scamper` and referenced in design-thinking skills.
- Use these alongside the multi-agents and academic-apis folders in Okaro for full innovation + research workflows.


## Core CAD / EDA tools (added)

| Folder | Tool | Official source | Notes |
|--------|------|-----------------|-------|
| `FreeCAD/` | FreeCAD | https://github.com/FreeCAD/FreeCAD | Full parametric 3D CAD, FEM, CAM |
| `openscad/` | OpenSCAD | https://github.com/openscad/openscad | Code-based solid modeling |
| `cadquery/` | CadQuery | https://github.com/CadQuery/cadquery | Python parametric CAD (OCCT) |
| `build123d/` | build123d | https://github.com/gumyr/build123d | Modern Python CAD library |

These complement the existing code-CAD, text-to-CAD, and maker lists already in this folder.
